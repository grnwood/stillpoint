# Attachments

Attachments keep files in context with the page you are working on.
- Files are stored in the same folder as the page.
- This keeps notes and supporting artifacts together.
- Instead of asking "Where is that file?", open the page and the files are right there.

## Core Workflow
- Drag and drop files into the editor to attach them.
- Use the `+` button in the Attachments panel to add files from your system.
- Select items and use `-` to remove attachments.
- Double-click an attachment to open it.
- Use the folder button to open the page folder in your file manager.

## Images
- Pasted images are saved as attachments for the current page.
- Images can be embedded inline directly in your note.
- This is useful for screenshots, whiteboard captures, and visual references.

## Links and Reuse
- Drag an attachment from the panel into your note to create a link quickly.
- Keep related docs, exports, and media next to the page that explains them.
- For bigger topics, combine page links + attachment links so everything stays navigable.

## Homebase and Local Behavior
- Attachments live next to the page in the local vault folder.
- If Homebase is enabled, those local attachment files are included in sync.
- This also makes attachments easy to generate or update from local tools, scripts, and coding agents.

## Practical Tips
- Keep one page as the "hub" for a project and attach relevant files there.
- Use inline images for quick context, and keep larger source files as attachments.
