Sync & Sharing

Your vault. Your rules. Three great ways to share it.

Want effortless cloud sync, Git-powered history, or private encrypted infrastructure? StillPoint can do all three—without giving up local files, offline work, or ownership of your notes.

Compare the modes Help me choose

Local first is the constant

Every mode starts with a real folder of Markdown pages and attachments on your computer. StillPoint changes how the vault travels—not who owns it.

  • Cloud Folder: familiar and automatic
  • Git: versioned and inspectable
  • Homebase: encrypted and under your control
Choose your superpower

There is a mode for the way you actually work.

Keep one vault local, put another in the cloud, run a project through Git, and host your most private knowledge on Homebase. Each vault gets its own answer.

☁ Cloud Folder

The quickest route to “my notes are on my other computer.” OneDrive or Google Drive carries pages and attachments while StillPoint keeps its live databases, indexes, locks, and undo state safely on each device.

Pick it for: personal vaults, familiar setup, and low-friction sync.

</> Git

Turn your vault into a versioned knowledge project. Review beautiful diffs, save named versions, get remote updates, publish deliberately, and optionally create automatic backup commits.

Pick it for: exact history, technical teams, review, and automation.

⌂ Homebase

StillPoint-native distributed sync with encrypted server objects, offline-first local copies, user roles, conflict review, and device-local recovery before a pull replaces anything.

Pick it for: privacy, self-hosting, managed access, and control.

Cloud Folder

Use the cloud you already know.

Cloud Folder is deliberately boring in the best way. Put the vault in OneDrive or Google Drive, mark the whole folder available offline, and let the provider move your portable content between computers.

The important nerdy bit: StillPoint relocates databases, indexes, locks, and undo state to device-local storage. That avoids asking a file-sync service to replicate a live application database.

Cloud Folder ground rules

  • Keep the entire vault available offline.
  • Close it on one computer before opening it on another.
  • Let the provider finish syncing before switching devices.
  • Review Current, Cloud, and Merge when a text conflict appears.

Git without leaving StillPoint

  • See every changed file and its status.
  • Review rich side-by-side or unified diffs.
  • Save named vault versions or routine backup commits.
  • Get updates and publish when you decide.
Git

Your notes can have engineering-grade history.

Git is for people who want to know exactly what changed, when, and why. StillPoint brings the everyday workflow into a friendly visual rail while leaving the repository completely usable from your terminal and favorite hosting service.

StillPoint never pulls or merges in the background. Remote changes stay deliberate, and normal Git remotes receive plaintext files—so choose a private remote when the content calls for it.

Homebase

Encrypted, local-first sync on your infrastructure.

Homebase keeps a full working copy on every device and synchronizes encrypted objects through a server you choose. Accounts and roles manage access; your client-side passphrase protects the content.

Before a pull overwrites or removes a local file, Local Recovery preserves the prior bytes on that device. Large or unusual pulls pause for review instead of quietly rolling over your work.

Power-user friendly

The vault stays open to your whole toolkit.

Whichever mode you choose, the working vault remains real local files. Open it in a terminal and let editors, scripts, importers, TUIs, or coding agents create and improve pages. Then let Cloud Folder sync, Git save and publish, or Homebase synchronize the result.
