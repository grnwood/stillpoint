Folder Navigator

Your notes are home base. Your files can stay where they are.

You are working in your StillPoint vault, keeping the decisions, tasks, and running story of a project. But the project itself is a codebase, a client folder, or a tree of files that should not become a notes vault. Folder Navigator gives that work a StillPoint-shaped window of its own.

A sidecar workspace

Stay in your system without putting everything inside it.

StillPoint remains the place where the project makes sense: meeting notes, design choices, questions, tasks, and the daily trail. Folder Navigator sits beside it for the project files themselves. It opens the folder as-is, in a separate window with a distinct folder-badged icon, and leaves the structure untouched.

Ranger-inspired

Fast with a keyboard, comfortable with a mouse.

Folder Navigator takes its cue from keyboard-first file browsers such as Ranger. Move through the folder tree with familiar vi keys, jump to a file with Quick Open, search names and text, and keep related files in tabs. If vi mode is not your thing, the native tree, menus, and mouse interactions work exactly as expected.

It feels like StillPoint because the point is not another tool. The point is keeping your flow.

Quick Open

Find a file by name or path without unfolding the whole tree.

A quick way back

Pin the folders that belong with a vault.

Add a Folder Navigator shortcut to a StillPoint vault's bookmark bar. One click reopens the external working folder, while the folder icon makes it clear that you are launching files—not navigating to another note page.

Inside Folder Navigator, you can separately bookmark important files and subfolders, filter the tree to the part you care about, and restore your working tabs the next time that root opens.

What does not happen

  • The folder is not imported into your vault.
  • Its layout is not converted to StillPoint pages.
  • Its contents are not added to your vault's AI or search index.
  • The window does not need StillPoint's server to keep running.
Start from StillPoint

Open a folder and keep going.

Choose File → Open Folder Navigator… for a one-off workspace, or File → Bookmark Folder Navigator… to pin a folder to the current vault. Each root opens independently and can stay open even when the main StillPoint window closes.
